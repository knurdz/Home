description: >-
  Deploy Sprint is Knurdz's hands-on DevOps hackathon built exclusively for
  University of Moratuwa undergraduates. Knurdz organizes the program end to
  end; the Leo Club of University of Moratuwa partners with us so the experience
  stays inside the university, with campus logistics, undergraduate outreach,
  and on-the-ground coordination alongside Knurdz's DevOps program. Teams
  register online, complete a mandatory physical bootcamp and online workshop,
  pass a virtual qualifier, then compete in a six-hour campus finale as release
  engineers shipping pre-built features to dedicated cloud VPS nodes through
  GitHub Actions. No SSH, no greenfield builds.

programPhases:
  - title: Announcement & registrations
    date: 'Jun 6 – Jul 3, 2026 · 12:00 PM → 11:59 PM'
    description: >-
      University of Moratuwa undergraduates register teams of three to four
      online through July 3. Complete the mandatory bootcamp and qualifier to
      compete on campus July 19.
  - title: Hands-on bootcamp
    date: 'Jul 5, 2026 · mandatory · physical on campus'
    description: >-
      Mandatory physical on-campus prep before the qualifier: Git branching,
      Docker, GitHub Secrets, and cloud deploy workflows. Attendance is required
      to stay in the pipeline.
  - title: Online workshop
    date: Leading into the qualifier
    description: >-
      Industry-led online session on GitHub Actions, complementing the bootcamp
      so teams are ready to run automated deploy workflows before the virtual
      qualifier.
  - title: Virtual qualifier
    date: 'Jul 5–6, 2026'
    description: >-
      Filters applicants to the final 15 teams (up to 60 students) before anyone
      touches live cloud servers.
  - title: Feature rollout finale
    date: 'Jul 19, 2026 · 6-hour physical hackathon on campus'
    description: >-
      Release cycles, live cloud deploys through GitHub Actions, judging, and
      prizes. Everyone acts as release engineers integrating pre-built features
      into live VPS nodes.
