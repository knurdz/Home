summary: >-
  Knurdz ran hands-on workshops and a live build where undergraduates learned
  digital logic from the ground up and assembled registers, decoders, and other
  CPU building blocks into a working 8-bit processor.
description: >-
  OCTAII was a Knurdz workshop and live-build program held across August and
  September 2025. Sessions walked participants from basic logic gates through
  registers, binary decoders, arithmetic blocks, and the control paths that tie
  them together — culminating in a collaborative build of an 8-bit CPU. The
  series mixed classroom teaching with bench time so theory mapped directly to
  breadboards and wire.

plannedHighlights:
  - Logic gates, truth tables, and combinational building blocks
  - Registers, latches, and clocked storage
  - Binary decoders and multiplexing for control and datapath wiring
  - ALU-style arithmetic and glue logic toward a full 8-bit datapath
  - Live build sessions assembling and testing the CPU on the bench
programPhases:
  - title: Foundations — logic gates
    date: August 2025
    description: >-
      Introduced Boolean logic, gate-level primitives, and how simple combinational
      circuits combine into useful building blocks on the breadboard.
  - title: Storage and decoding
    date: Early September 2025
    description: >-
      Workshops on registers and binary decoders — how the machine remembers
      state and how instruction or control patterns select the right datapath.
  - title: Datapath components
    date: September 2025
    description: >-
      Built and integrated arithmetic, bus wiring, and supporting glue logic
      toward a coherent 8-bit datapath students could trace signal by signal.
  - title: Live CPU build
    date: September 2025
    description: >-
      Collaborative live-build sessions to wire, debug, and bring up the 8-bit
      CPU as a capstone to the workshop series.

OCTAII treated computer architecture as something you build with your hands — not just a diagram in a textbook. From the first logic-gate exercises through registers, decoders, and the live CPU bring-up, the goal was a shared mental model of how an 8-bit machine actually executes.
