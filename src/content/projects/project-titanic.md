## Overview

Project Titanic is a multipurpose application built for university students, combining six core features into a single platform for campus life, collaboration, and productivity.

## The Problem

Students juggle fragmented tools for messaging, scheduling, marketplace listings, and campus services. Project Titanic aims to unify the most-used workflows into one cohesive experience.

## Planned Features

- Six integrated feature modules for everyday student needs
- Cross-platform support on mobile and web
- Marketplace and community-oriented workflows under active development on `feature/marketplace`
